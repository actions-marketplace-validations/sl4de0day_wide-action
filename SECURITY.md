# Security Policy

## Supported Versions

Security fixes are released on `main` and tagged under the latest release version and `v1`.

## Reporting a Vulnerability

If you discover a security vulnerability in Wide Action (for example, SARIF secret masking bypass, remote bundle checksum bypass, or workflow token leakage):

1. Report it privately via GitHub Security Advisories at https://github.com/sl4de0day/wide-action/security/advisories/new.
2. Include reproduction steps, action configuration inputs, and minimal logs.
3. Wait for a patched release before public disclosure.
